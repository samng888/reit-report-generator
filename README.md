This project features an automated financial reporting engine designed to evaluate global Real Estate Investment Trusts (REITs) with zero manual intervention. 
Built using Python, Pandas, and Openpyxl, it seamlessly ingests live market data and bond yields to calculate essential financial metrics and risk tiers. 
The system also integrates Matplotlib to dynamically generate and embed technical moving-average charts directly into a multi-tab Excel dashboard. 
Ultimately, it transforms hours of tedious manual spreadsheet formatting into a streamlined, 1-click execution pipeline.
